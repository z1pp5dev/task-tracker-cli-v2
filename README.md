
# Task Tracker CLI v2

A robust, command-line task management application built in Python featuring persistent JSON storage, a clean multi-layer modular architecture, categorized task views (Pending vs. Completed), and defensive error handling.
## Features

Structured Data Dictionaries: Tracks individual tasks as dictionaries containing text strings and boolean completion states ({"task": str, "completed": bool}).

Categorized Views: Dynamically parses and separates tasks into distinct Pending and Completed sections with clear 1-based indexing.

Complete CRUD Operations: Add tasks, view categorized items, mark tasks as complete, and remove tasks cleanly.

Resilient Error Recovery: Bulletproof error handling prevents terminal crashes from non-numeric menu inputs, missing files, or empty file corruption.
## Installation

Prerequisites
Python 3.x installed on your local machine.

Installation & Execution
Clone the repository to your local machine:

Bash
git clone https://github.com/z1pp5dev/task-tracker-cli-v2
Navigate into the project directory:

Bash
cd task-tracker-cli-v2
Run the application:

Python
python Task_Tracker_CLI_v2.py
